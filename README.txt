# Cubie Magada — BSIT Portfolio

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling and theme
- `script.js` — navigation, certificate carousel, and back-to-top interactions

## Run locally
Open `index.html` in a browser. An internet connection is needed for Bootstrap, Bootstrap Icons, and Google Fonts CDNs.

## Add your own images
Create an `assets` folder beside `index.html`, then add:
- `profile.jpg` — your portrait
- `study-desk.jpg` — optional study photo
- `project-fbc.jpg`, `project-vps.jpg`, `project-network.jpg`, `project-ecommerce.jpg` — project screenshots
- `certificates/certificate-1.jpg`, `certificate-2.jpg`, etc. — certificate images
- `resume.pdf` — your resume

Missing images display styled placeholders. Use your real details and only list skills/certifications you have actually earned. Update email, social links, education, project links, and text in `index.html` before publishing.
