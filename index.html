THESIFY Project

THESIFY: An AI-Powered Academic Thesis Management and Panel Evaluation System with OCR-Based Panel Annotation Capture

HTML5 CSS3 JavaScript Bootstrap 5 Tailwind CSS Node.js Netlify Functions Supabase Groq API Google Cloud Vision API / Tesseract OCR Visual Studio Code GitHub

THESIFY is a group capstone project designed to simplify and organize the academic thesis process, from title hearing to final defense. The system allows students and faculty to manage thesis documents, track research progress, schedule defenses, and conduct digital panel evaluations. It also includes AI-assisted academic writing support and OCR technology to convert handwritten panel comments into digital text, making thesis management more efficient and accessible.

AssetEase Project

AssetEase – Room Reservation and Equipment Borrowing System

PHP MySQL HTML CSS Bootstrap JavaScript AJAX PHPMailer AI / NLP XAMPP

AssetEase is a web-based Room Reservation and Equipment Borrowing System developed for Fellowship Baptist College. It allows students, teachers, and staff to reserve rooms and borrow equipment online. The system provides real-time availability checking, reservation management, automated email notifications, and an administrator dashboard to improve school resource management.

MyCRM Project

MyCRM – Customer Relationship Management System

PHP MySQL HTML CSS JavaScript XAMPP

A web-based CRM system for managing contacts and customer information, with features for assigning values, adding notes, and labeling leads and customers.
